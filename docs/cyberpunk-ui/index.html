@laddtnov/cyberpunk-ui

A zero-dependency cyberpunk CSS kit — neon design tokens, glow/glitch/scanline effects, glassmorphism components, and a WCAG-aware light theme. No build step, no JavaScript, no runtime.

Install Design Tokens Components Effects Theming Accessibility

Install

npm i @laddtnov/cyberpunk-ui

CDN (no install needed)

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@laddtnov/cyberpunk-ui@0.2.0/tokens.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@laddtnov/cyberpunk-ui@0.2.0/cyberpunk-ui.css">

Design Tokens

All colors are CSS custom properties with fallbacks. Override them to theme your site:

VariableDefaultDescription
--cy-neon-cyan#00f2ffPrimary accent — cyan neon
--cy-neon-pink#ff00ffSecondary accent — magenta
--cy-neon-purple#9d00ffTertiary — purple glow
--cy-bg#0a0a0cDeep void background
--cy-text#e0e0e0Primary text color
--cy-font-display'Orbitron'Display font family
--cy-font-mono'Share Tech Mono'Monospace font family
--cy-font-body'Rajdhani'Body font family

Theming

The package ships with a dark theme by default. To use the light theme, add data-theme="light" to the <html> element:

<html lang="en" data-theme="light">

Accessibility

  • WCAG-aware light theme with sufficient contrast ratios
  • All interactive elements have visible focus rings
  • prefers-reduced-motion respected — animations disabled for users who prefer it
  • Semantic HTML encouraged — use <button> for actions, <a> for navigation
  • Custom properties include fallbacks for graceful degradation
